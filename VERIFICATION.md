# Проверка перед публикацией

Дата: 26 октября 2026 года.

## Текущая версия

Команда:

```powershell
.\.venv\Scripts\python.exe scripts/check.py --javascript
```

Результат: **54 Python-теста прошли за 11,10 с; 27 JavaScript-тестов прошли за 0,154 с**. Ошибок нет. Python сообщил одно предупреждение об устаревающем способе использования httpx внутри Starlette TestClient; оно не препятствует выполнению тестов.

Добавлены проверки облачного PostgreSQL: обработка строки Neon, обязательная проверка TLS, работа без Redis и отказ от перехода на временную SQLite при сбое подключения. Эти тесты используют подмену соединения и не выдаются за проверку реальной облачной базы.

Проверяются API, локальное хранение, поток обновлений, сохранённые планы, расчёт озеленения, схема пилотных участков, отчёт, языки и управление анимациями. Проверки JavaScript выполняются без реального браузера и не являются замером FPS на конкретном компьютере.

## Короткая сквозная приёмка

Сохранён [результат отдельного автономного запуска](docs/verification/acceptance.json): 31,76 с потока, 16 обновлений и 640 записей, проверка расчёта, объяснений и восстановления после перезапуска. Это результат предыдущей приёмки; он не выдаётся за повторный замер после очистки.

Для воспроизведения:

```powershell
.\.venv\Scripts\python.exe scripts/acceptance.py --seconds 30
```

Приёмка запускает отдельный процесс со свежими данными, не затрагивает рабочую базу и сохраняет новые результаты в `artifacts/acceptance/`. Эта папка создаётся автоматически и не включается в Git.

## Что сохранено в репозитории

- Пример полного расчёта: `examples/optimization.sample.json`.

Промежуточные видео, зависимости рендера, временные скриншоты, старые поставки Argon и установленные для видео навыки убраны. Исторические рабочие файлы из `artifacts/` сохранены отдельно в локальном восстанавливаемом архиве, а не публикуются как часть приложения.

## Границы проверки

Реальная сеть физических датчиков, качество прогнозов на полевых наблюдениях и фактический эффект посадок не подтверждены. Docker-стек PostgreSQL/Redis не объявляется заново проверенным. Системную печать PDF ранее подтвердил пользователь; автоматические тесты проверяют формирование и передачу отчёта.

## Облачная проверка 26 октября 2026

ASTRA размещена на https://astra-n2xd.onrender.com/ (Render Free + Neon Free, Frankfurt). Проверены HTTPS, 40 зон, SHAP, расчёт 1000 вязов, чтение сохранённого плана и WebSocket: снимок и новое обновление по 40 зонам. После пересоздания контейнера сохранённый JSON плана совпал с исходным. Рабочий режим — `cloud`, PostgreSQL и очередь в памяти.

При проверке погодный API Open-Meteo вернул HTTP 429 с адреса Render. Для этого случая добавлен прогноз MET Norway с собственным источником и временем. Автотест проверяет переключение, кэш до Expires, запрос If-Modified-Since и сохранение последнего доступного фона при сбое обоих источников.

Итоговая проверка версии `6d43f4c` на Render: оба фоновых канала `live`, воздух — Open-Meteo / CAMS, погода — MET Norway Locationforecast. Исходный план сохранился и после этого обновления контейнера. В Chrome через публичный интерфейс выполнен новый расчёт 1000 вязов; отчёт сформирован, источник MET Norway указан, кнопка печати/PDF доступна. Повторный системный диалог печати не запускался.
