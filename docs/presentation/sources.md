# Справочник источников, чисел и ограничений ASTRA

Этот документ собирает в одном месте все источники чисел, правил расчёта и проверок для презентации **`ASTRA_GreenHack.pptx`** и **`ASTRA_GreenHack.pdf`** (предварительный отбор **GreenHack Kazakhstan 2026**). Сами слайды освобождены от мелких сносок и ссылок, чтобы не перегружать визуальное восприятие жюри.

## 4. Раскрытие использования инструментов ИИ (п. 5.6 и п. 9.1–9.2 Положения GreenHack Kazakhstan)

По правилам академической честности Положения фиксируем роль инструментов ИИ:

1. **Где применялись инструменты ИИ:**
   - В самом приложении ASTRA используется модель машинного обучения (`LightGBM`) для прогноза общего индекса нагрузки на 3 часа вперёд и сравнения вариантов прогноза пыли, а также метод `SHAP` для наглядного показа вклада факторов.
   - При сборке презентационного пакета ИИ-помощник разработчика использовался для написания скрипта вёрстки слайдов (`pptxgenjs`), автоматической проверки отступов и подготовки текста выступления по проверенным материалам проекта.
2. **Что проверено по фактам и остаётся под ответственностью команды:**
   - Все числа сверены с сохранённым расчётом `example_run_1000_elm.json`, таблицами проверок в `benchmarks/` и открытыми публикациями Казгидромета, Бюро национальной статистики и службы Open-Meteo / CAMS.
   - Расчётные показатели модели нигде не выдаются за результаты уличных замеров, а поля с составом команды на титульном слайде оставлены для заполнения реальными участниками перед отправкой заявки.
