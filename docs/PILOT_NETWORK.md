# Демонстрационная сеть по городским ориентирам

Версия `landmarks-v2`, 25 октября 2026 года. Каталог из 40 точек находится в
`app/core/pilot_sites.json`; сценарные профили — в `app/core/zones.py`.

Вместо пяти прямоугольных сеток используются фиксированные приблизительные
ориентиры, распределённые по городской территории. Это авторская схема для
демонстрации, не результат обследования площадок и не сеть действующих датчиков.
Точки обозначают окружение ориентира: возможная установка на тротуаре или
конкретном земельном участке не проверялась. При подготовке реального пилота
нужны уточнение координат, границ, землепользования, доступа и условий установки.

У каждой точки есть название на RU/EN/KK, тип окружения и ссылка на карту.
Ссылки OpenStreetMap открывают выбранную координату для проверки, а не служат
доказательством существования станции. Автоматическая выгрузка геометрии OSM
через публичные Overpass-сервисы оказалась недоступна; импорт не выполнялся.

## Логика сценария

- Парки и бульвары — зелёные фоновые точки с низким условным трафиком.
- Жилые кварталы — больше условного населения и умеренная транспортная нагрузка.
- Дорожные коридоры — выше условный трафик, меньше зелени и места для посадок.
- Промышленное окружение — мало зелени и меньше условного постоянного населения.
  Реальные выбросы предприятий и перенос шлейфа ветром не моделируются.

NDVI, плотность, трафик, население, площади и вместимость посадок — допущения.
Площади и население относятся к условным непересекающимся расчётным ячейкам,
а не к кадастровым участкам, площади всего парка или переписи населения.
Пять групп районов сохранены для совместимости сценариев; они не утверждают
действующие административные границы города.

## Совместимость и история

ID станций сохранены. Новые показания содержат `network_version`, история и
последний срез отбираются по текущей версии. При переходе в середине минуты
минутная агрегация начинает новую серию. Старые записи остаются в базе до
обычной очистки по сроку хранения; сохранённые расчёты сохраняют исходные
координаты и параметры. Они не выделяют одноимённые станции новой схемы.
Сигнатура ML включает каталог зон, поэтому модель автоматически переобучается
после изменения каталога, не используя старый артефакт с новыми признаками.
