# Пример выгрузки ASTRA

`optimization.sample.json` — настоящая выгрузка из проверенного интерфейса 25 октября 2026 года: Есиль, сосна, 1000 деревьев, горизонт 10 лет, цена саженца 20 000 ₸. Городской фон получен из Open-Meteo; все 40 узлов и экологический эффект являются расчётной симуляцией.

Первый год по указанным сценарным ценам — 34 800 000 ₸. Этот файл предназначен для воспроизводимой проверки формата, в том числе отчёта Argon. Он не является измерением результата посадок, коммерческим предложением или актуальным фоном на момент открытия.
